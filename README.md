# Paddle Out AI — Landing Page

Public landing page for Paddle Out AI (paddleoutai.com), hosted on GitHub Pages.

## Structure

- `index.html` — the entire single-page site
- `style.css` — all styling
- `assets/` — logo files
- `CNAME` — custom domain config for GitHub Pages

## Editing

This is plain HTML/CSS, no build step. Open `index.html` in any editor, change the text, save, commit, push.

To preview locally, just open `index.html` in a browser, or run a simple local server:

```
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploying

Pushing to `main` deploys automatically via GitHub Pages.
